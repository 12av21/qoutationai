# QuotePilot page map

The prototype uses one SPA entry point (`index.html`) with view routes rendered by `src/js/app.js`.

- `landing`: public product page and entry CTAs
- `dashboard`: metrics, AI activity, chart, recent quotations
- `create`: requirement capture and AI analysis start
- `analysis`: extracted requirement review
- `matching`: recommended products and alternatives
- `pricing`: pricing, discount, GST, and totals
- `validation`: validation checklist and readiness score
- `preview`: professional quotation document
- `approvals`: human approval center
- `sent`: delivery confirmation
- `quotations`: quotation management table
- `catalog`: products and services catalog
- `agents`: AI agent command center
- `analytics`, `customers`, `inbox`, `integrations`, `settings`: supporting workspace views
